# Milestone Task Prompt

Use this compact frame for future implementation work:

```text
Milestone: <name>
Objective: <one measurable outcome>
In scope: <explicit files/behaviors>
Out of scope: <features that must not start>
Acceptance: <observable pass conditions>
Verification: <commands/runtime checks>
Deployment: none unless separately approved
```

Before work, load `AGENTS.md`, `.ai/context/current-state.md`, and only the context/skill/check files needed for the milestone. After work, reconcile `TASKS.md` and `current-state.md` with evidence.
