# Project Brief

Statement Collector's Piece is a WordPress/WooCommerce project for limited releases with a permanent no-restock promise.

Primary brand message: **Crafted. Limited. Never Restocked.**

## Product contract

Each release moves from limited availability to sold out and then permanent archive. Piece numbers may be used, but public total production or maximum-piece messaging is not part of the product model.

## Delivery approach

- Build a custom standalone theme for presentation and a custom core plugin for durable domain behavior.
- Use WordPress/WooCommerce extension APIs; never modify platform core.
- Develop locally from this repository, verify by milestone, package versioned ZIPs, and upload manually only in a separately approved release operation.

Current scope and evidence live in `current-state.md`; implementation boundaries live in `architecture.md`; immutable policy lives in `business-rules.md`.
