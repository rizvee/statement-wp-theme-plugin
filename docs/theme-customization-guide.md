# Statement Collector Theme Customization Guide

---

## 1. Customizer Controls (Appearance > Customize)

The Statement theme organizes all customization options under **Statement Design Settings**:
- **Global Palette & Layout**: Configure background ivory (`#FBFBFA`), surface white (`#FFFFFF`), ink typography (`#111111`), border colors, and container widths (1200px / 1440px).
- **Header & Navigation**: Adjust header height (64px) and sticky navigation properties.
- **Shop & Catalog**: Choose product grid columns (2, 3, or 4 columns) and toggle breadcrumbs.
- **Homepage Hero Slider**: Configure 4 campaign slides with desktop image, mobile image, eyebrow, heading, link, CTA text, and CSS focal alignment.

---

## 2. Page-Level Design Overrides

When editing any Page or Post in WordPress:
- In the right sidebar, open **Statement Design Settings**:
  - **Layout Width**: Default, Contained (1200px), Wide (1440px), Full Bleed (100%).
  - **Header Style**: Default, Transparent Overlay, Hidden.
  - **Footer**: Default, Hidden.
  - **Page Title**: Default, Hidden.

---

## 3. Options Export / Import (Appearance > Statement)

- **Export Settings**: Download a JSON snapshot of all active Customizer design settings.
- **Import Settings**: Upload a previously exported JSON settings file with automated pre-import backup.
- **Reset to Defaults**: Restore pure gallery factory defaults.
