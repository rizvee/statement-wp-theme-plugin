# Visual Reference & Competitor Pattern Analysis

Comparative analysis of client-supplied references (`marooclo.com`, `mertra.com`) and contemporary quiet-luxury fashion e-commerce storefronts.

Analysis Date: 2026-08-17
Target Application: Statement Collector's Piece (WordPress / WooCommerce)

---

## 1. Reference Deconstruction

### Reference A: Maroo (`marooclo.com/pages/raw-ceremony`)
- **Visual Rhythm**: Light-first canvas with disciplined typography. Uses high-contrast editorial photography interspersed with generous vertical padding (5rem–16rem section spacing).
- **Typography Strategy**: Pure neutral sans (`Inter`) pairing ultra-tight display letter spacing (`-0.03em`) on large headings with wide tracking (`0.1em`) on uppercase micro-eyebrows and metadata tags.
- **Imagery Scale**: 4:5 portrait frames dominate. Zero card borders, drop shadows, or decorative corner radii.
- **Copy Density**: Extremely low. 1–2 evocative sentences per release rather than verbose marketing paragraphs.
- **Drop Storytelling**: Clean transition from editorial statement into curated product pairs, followed by a lookbook sequence.

### Reference B: Mertra (`mertra.com/password`)
- **Access Gate Architecture**: Pure white background (`#FFFFFF`) with subdued graphite foreground (`#333333`), ultra-fine hairline dividers (`#E8E9EB` / `#C6C6C6`), and compact uppercase labels (10–12px with 0.08em tracking).
- **Form Controls**: Minimal single-line input with restrained border highlights and pill button.
- **Atmosphere**: Focus and exclusivity. The screen feels like an invitation rather than an authentication barrier.

## 2. Synthesized Architectural Patterns for Statement

| Dimension | Standard / Generic E-commerce | Statement Quiet-Luxury Standard |
|-----------|-------------------------------|----------------------------------|
| **Color Dominance** | Random banners & saturated accents | 80% Gallery Ivory / Warm White canvas with Ink Navy / Near Black contrast moments |
| **Typography** | Generic system fonts or serif body copy | High-contrast `Instrument Serif` editorial display paired with crisp `Inter` metadata |
| **Product Cards** | Boxed cards with shadows and borders | Borderless 4:5 portrait media, smooth 1.02 hover zoom, minimal title-left / price-right row |
| **Drop Narrative** | Cluttered tabbed sliders | Dedicated `/drops/` index & `/drop/<slug>/` editorial page with lookbook strip |
| **Size Guide** | Messy HTML table in description tab | Accessible slide-out / modal dialog with clean CM measurements |
| **Mobile UX** | Tiny buttons, cramped horizontal carousels | Full-width image stack, tactile tap targets (44px+), sticky Add-to-Bag drawer |
| **Copy Length** | Long marketing prose | 1-line evocative statements ("Crafted. Not Mass Made.", "Produced with intention, not volume.") |

## 3. Strict Negative Boundaries
- Do NOT clone proprietary logos, copy, or trademarked styling from references.
- Preserve Statement's distinctive geometric hexagon emblem and black/grey jacquard aesthetic.
- Preserve WooCommerce native data structures and cart/checkout flows without external dependencies.
